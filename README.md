# הטיול הגדול 🎒

אפליקציית ווב (PWA) בעברית לטיול הגדול – המזרח, דרום אמריקה ומרכז אמריקה. מותאמת לטלפון, עובדת גם בלי אינטרנט ואפשר להתקין אותה למסך הבית.

## מה יש באפליקציה
- **מפה ציורית של "שביל החומוס"** – מפה מצוירת בתוך האפליקציה (d3-geo + נתוני Natural Earth, בלי Google Maps ועובדת אופליין) עם ~100 מקומות: אטרקציות, אוכל, לינה, מסיבות, פסטיבלים, נקודות התארגנות, מוקדים ישראליים ואזהרות. כולל קיבוץ סיכות, סינון לפי קטגוריה ועונה, והוספת מקומות משלכם.
- **מקומות אמיתיים מ-Google (Places API New)** – חיפוש, "באזור שלי", השלמה אוטומטית, פרטי מקום ותמונות, מעל המקומות של הקהילה. כל מקום מסומן לפי מקורו (צוות / משתמש / Google), ודירוג Google מוצג בנפרד מדירוג הקהילה. המפתח נשמר בשרת בלבד – ראו [docs/GOOGLE_PLACES_SETUP.md](docs/GOOGLE_PLACES_SETUP.md). בלי מפתח האפליקציה ממשיכה לעבוד כרגיל.
- **ביקורות עם "עין ישראלית"** – כוכבים, טקסט, תמונה, מתי הייתם וכמה עלה, ותגיות כמו "בטוח לבד" ו"מוצף ישראלים".
- **מה חם עכשיו** – פסטיבלים החודש ובחודש הבא, ונקודות מפגש בשיא העונה.
- **"אני כאן"** – צ׳ק־אין במקום ושיתוף עם קישור שפותח אותו על המפה.
- **שאלות נפוצות ו"על הפרויקט"** – חזון, ניתוח שוק, מתחרים ו־SWOT.
- **יעדים** – 21 מדינות באסיה, בדרום אמריקה ובמרכז אמריקה ומקסיקו: ויזה לישראלים, עונה מומלצת, תקציב יומי, מטבע, שקעים, מספרי חירום, חב״ד, מקומות חובה וטיפים.
- **הטיול שלי** – בניית מסלול (הוספה, סידור, ימים) והערכת תקציב כולל טיסות וביטוח.
- **יומן והוצאות** – זיכרונות יומיים, מעקב הוצאות לפי קטגוריה ומדינה, והשוואה לתקציב המתוכנן.
- **ממיר מטבע** – שערים עדכניים (ExchangeRate-API), עם שמירה מקומית ושערים משוערים כשאין אינטרנט.
- **גיבוי ושחזור** – הורדת כל המידע לקובץ JSON וטעינה חזרה.
- **צ׳קליסט** – רשימת הכנות וציוד לפי יעד, עם שמירת התקדמות.
- **טיפים** – תכנון, כסף, בריאות, בטיחות ותרבות.
- **שפות** – משפטים שימושיים עם הגייה בעברית והשמעה קולית.

כל הנתונים האישיים נשמרים מקומית במכשיר (localStorage).

- **חשבונות משתמשים (Supabase)** – הרשמה וכניסה, סנכרון בין מכשירים וביקורות משותפות לקהילה. ראו [docs/SUPABASE_SETUP.md](docs/SUPABASE_SETUP.md). בלי הגדרה האפליקציה ממשיכה לעבוד מקומית.

## העלאה לאוויר
ראו [docs/FIREBASE_DEPLOY.md](docs/FIREBASE_DEPLOY.md) (Firebase Hosting + Function) ו-[docs/WEEKLY_PLACES.md](docs/WEEKLY_PLACES.md) (עדכון שבועי).

## פיתוח
```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות
npm run build    # בנייה ל-dist/
```

משתני סביבה (`GOOGLE_MAPS_API_KEY`, `ALLOWED_ORIGINS`) – ראו `.env.example` והמדריך ב-`docs/`.

התוכן נמצא ב-`src/data/` – מדינות ב-`countries.ts`, מקומות על המפה ב-`places.ts`.

השכבה הקהילתית (`src/community.ts`) שומרת כרגע הכל במכשיר. היא בנויה כך שאפשר להחליף את השמירה המקומית בשרת משותף (למשל Supabase/Firebase) כדי שביקורות ו"אני כאן" יתעדכנו אצל כל המטיילים.

> המידע כללי. תנאי ויזה, מחירים ואזהרות מסע משתנים – יש לבדוק מול מקורות רשמיים לפני הטיסה.
