# הטיול הגדול 🎒

אפליקציית ווב (PWA) בעברית לטיול הגדול – המזרח, דרום אמריקה ומרכז אמריקה. מותאמת לטלפון, עובדת גם בלי אינטרנט ואפשר להתקין אותה למסך הבית.

## מה יש באפליקציה
- **יעדים** – 21 מדינות באסיה, בדרום אמריקה ובמרכז אמריקה ומקסיקו: ויזה לישראלים, עונה מומלצת, תקציב יומי, מטבע, שקעים, מספרי חירום, חב״ד, מקומות חובה וטיפים.
- **הטיול שלי** – בניית מסלול (הוספה, סידור, ימים) והערכת תקציב כולל טיסות וביטוח.
- **יומן והוצאות** – זיכרונות יומיים, מעקב הוצאות לפי קטגוריה ומדינה, והשוואה לתקציב המתוכנן.
- **ממיר מטבע** – שערים עדכניים (ExchangeRate-API), עם שמירה מקומית ושערים משוערים כשאין אינטרנט.
- **גיבוי ושחזור** – הורדת כל המידע לקובץ JSON וטעינה חזרה.
- **צ׳קליסט** – רשימת הכנות וציוד לפי יעד, עם שמירת התקדמות.
- **טיפים** – תכנון, כסף, בריאות, בטיחות ותרבות.
- **שפות** – משפטים שימושיים עם הגייה בעברית והשמעה קולית.

כל הנתונים האישיים נשמרים מקומית במכשיר (localStorage).

## פיתוח
```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות
npm run build    # בנייה ל-dist/
```

התוכן נמצא ב-`src/data/` – כדי להוסיף מדינה או לעדכן מידע, ערכו את `countries.ts`.

> המידע כללי. תנאי ויזה, מחירים ואזהרות מסע משתנים – יש לבדוק מול מקורות רשמיים לפני הטיסה.
